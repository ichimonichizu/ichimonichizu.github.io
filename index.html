一問一図 制作ツール

このページは、YouTube チャンネル「一問一図」（@ichimonichizu）の運営者が、自分のチャンネルの運営だけに使う制作ツール（以下「本ツール」）の説明です。

本ツールがすること

本ツールは YouTube API サービス（YouTube Data API v3、YouTube Analytics API）を使い、運営者が許可したチャンネルに対して、次のことだけを行います。

  • 制作した動画とサムネイル画像を、非公開でアップロードする（公開は運営者が YouTube Studio で手動で行います）
  • アップロード済みの動画が公開されたかどうかを確認する
  • チャンネルの再生回数・総再生時間・登録者の増減・推定収益などの集計値を取得し、運営の振り返りに使う

本ツールは一般の方に向けて提供しているアプリではありません。運営者以外の Google アカウントのデータにアクセスすることはありません。
