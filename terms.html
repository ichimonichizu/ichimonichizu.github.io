利用規約

制定日: 2026年11月18日 ／ 最終更新日: 2026年11月18日

この利用規約は、YouTube チャンネル「一問一図」の運営者（以下「運営者」）が自分のチャンネルの運営に使う制作ツール（以下「本ツール」）の利用条件を定めるものです。

1. 本ツールの性格

本ツールは運営者が自分の YouTube チャンネルを運営するためだけに使うもので、一般の方への提供や販売は行っていません。運営者以外の方は、本ツールの認可画面で許可を与えないでください。

2. YouTube の規約

本ツールは YouTube API サービスを利用しています。本ツールの利用には YouTube 利用規約が適用されます。Google による情報の取り扱いは Google プライバシーポリシーのとおりです。

3. 本ツールが行う操作

本ツールは、動画とサムネイル画像を非公開でアップロードし、チャンネルの集計値を読み取ります。動画を公開する操作、既存の動画を削除・変更する操作、コメントを書き込む操作は行いません。動画の公開は、運営者が YouTube Studio で手動で行います。

4. 情報の取り扱い

本ツールが扱う情報については、プライバシーポリシーに定めます。

5. 免責

運営者は、本ツールの動作の正確さや継続を保証しません。YouTube API サービスの仕様変更などにより、本ツールが予告なく動かなくなることがあります。

6. 改定

この規約を改定するときは、このページを更新し、最終更新日を改めます。

7. お問い合わせ

お問い合わせは、GitHub の Issues で受け付けています（投稿には GitHub アカウントが必要です。投稿内容は公開されるため、個人情報は書かないでください）。
